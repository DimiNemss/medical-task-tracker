# Swagger API Documentation

После запуска приложения документация Swagger доступна по адресу:

```text
http://localhost:3000/api-docs
```

Документация содержит описание всех доступных API-методов и позволяет выполнять запросы непосредственно из браузера.

В системе доступны следующие группы методов:

**Tasks**

Управление задачами:

* получение списка задач;
* получение задачи по идентификатору;
* создание задачи;
* обновление задачи;
* удаление задачи.

При получении списка задач поддерживается фильтрация по статусу и диапазону дат, а также пагинация результатов.

Поддерживаются следующие типы периодичности:

* `none` — разовая задача;
* `daily` — каждый n-й день;
* `monthly` — на определённое число месяца;
* `specific_dates` — на конкретные даты;
* `even_days` — только на чётные дни месяца;
* `odd_days` — только на нечётные дни месяца.

**Tags**

Управление тегами:

* получение списка тегов;
* получение тега по идентификатору;
* создание тега;
* обновление тега;
* удаление тега.

В системе присутствуют обязательные системные теги:

* отчетность;
* операции;
* звонок.

Системные теги доступны для использования в задачах, однако их изменение и удаление запрещено.

**Task Tags**

Связывание задач и тегов:

* добавление тега к задаче;
* удаление тега из задачи.

Одна задача может содержать несколько тегов.

**Occurrences**

Управление отдельными экземплярами периодических задач.

Поддерживаются следующие операции:

* изменение статуса конкретного экземпляра;
* отмена отдельного экземпляра;
* перенос экземпляра на другую дату;
* изменение названия и описания отдельного экземпляра;
* полный отрыв экземпляра от базового правила периодичности.

Для хранения таких изменений используется сущность `TaskOccurrence`.

Примеры использования доступны непосредственно в Swagger UI через кнопку **Try it out** для каждого метода.
